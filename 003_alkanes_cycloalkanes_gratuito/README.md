## 📌 Activity Overview

This repository contains my digital naming portfolio for Asynchronous Activity No. 3. The activity focuses on mastering IUPAC nomenclature through a two-way translation process:

* **Part A (Cards A01-A10):** Translating given bond-line structures into systematic IUPAC names by identifying the parent chain, numbering for lowest locants, and alphabetizing substituents.

* **Part B (Cards B01-B10):** Decoding given IUPAC names to predict molecular formulas and drawing the corresponding bond-line structures.

All structural checks and back-checks were performed using the rules-based naming engine, **The Alkane**.
